# Tombala (Bingo) Game

A visually appealing and interactive Tombala (Bingo) drawing application built with React, Vite, and Tailwind CSS. This app is designed for hosting fun game nights, especially for New Year's Eve celebrations.

## Features

- **Interactive Number Drawing:** Randomized drawing with animations and sound effects.
- **Real-time Board:** Track all drawn numbers on a clean, responsive board.
- **Card Generator:** Generate and print custom Tombala cards for players.
- **Surprise Prize System:** Optional automated prize draw flow to make the game more exciting.
- **Customizable:** Upload your own logo and change the event year.
- **Sound Manager:** Multiple sound effects for drawing and winning.
- **Persistence:** Game state and settings are saved in local storage.

## Demo

You can host this app on any static hosting service like GitHub Pages, Vercel, or Netlify.

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/tombala-game.git
   cd tombala-game
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
